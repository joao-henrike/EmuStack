ARQUITETURA DE ISOLAMENTO

Ambientes de console

Cada perfil roda em um contêiner próprio, com jogos, firmware/BIOS, saves, configurações, logs e binários adicionais separados. O dashboard é o orquestrador; não recebe mounts de dados nem acesso ao socket do Docker.

▤
ISO
Isolamento de dados por padrão

Os ambientes usam redes bridge distintas e não se comunicam diretamente. GPU, display e áudio são infraestrutura compartilhada quando configurados; isso não compartilha arquivos de jogos, saves ou firmware.

Limite técnico explícito: separar contêineres não cria suporte de emulação que o upstream não tem. O botão de sistema original só aparece para perfis com um caminho real detectado; firmware/BIOS e dados de sistema não vêm incluídos.

BOOT DO SISTEMA ORIGINAL

Consoles completos

Quando o emulador consegue inicializar o firmware e o menu real, o EmuStack chama esse caminho. Não desenhamos dashboards falsos nem distribuímos firmware proprietário.

▣
SYS
Interface original = firmware real em execução

O EmuStack não desenha dashboards falsos: os menus vêm do sistema/BIOS/NAND/HDD fornecido e executado pelo emulador. A aparência e as funções podem diferir do console físico quando o emulador ainda tem limitações.

ⓘ

Sem promessas falsas: PS3/XMB, PS2/BIOS, Xbox original e menus Nintendo só aparecem como bootáveis quando o caminho real está detectado e existe suporte do emulador. Xbox One/Series, Xbox 360, PS4/PS5 e Switch permanecem indisponíveis para boot completo nesta integração, mesmo que um jogo individual possa ser iniciado por outro caminho.
