ARQUITETURA DE ISOLAMENTO

Ambientes de console

Cada perfil usa um contêiner e diretórios persistentes próprios.

Isolamento por padrão

Redes e dados de cada ambiente são separados. GPU, display e áudio podem ser compartilhados se explicitamente configurados; arquivos de jogos, saves e firmware não são compartilhados.

BOOT DO SISTEMA ORIGINAL

Sistemas originais

O menu real vem do firmware executado pelo emulador. O EmuStack não desenha dashboards falsos.

Sem promessas falsas

O boot depende de suporte upstream e de arquivos de sistema válidos. Um dashboard do HDD não é comprovado pela simples existência de um arquivo de configuração.
